## 📌 项目详解

一个支持笔记本、代理、RAG、语音和图像的开源 AI 工作台，涵盖 OpenAI、Anthropic、Google、xAI 或通过 Ollama/vLLM 本地模型。 拥有 83 星的高人气和活跃开发，针对支持多模型和开源许可的独特 AI 工作台的利基市场，通过 SaaS 或 API 具有强大的盈利潜力。 根据 BSL 1.1 许可证（两年后自动转换为 Apache-2.0），存在 240 个开放问题，开发活动活跃。

该项目通过提供一个统一的平台来支持多种 AI 功能，填补了 AI 生态系统中的空白，并利用开源许可吸引开发者和企业。

## 🚀 应用前景

非常适合需要多功能 AI 平台（如笔记本、代理和 RAG）的开发者和企业，具有 SaaS、API 或本地解决方案的潜力。


## 🔧 技术栈

使用 TypeScript 构建，支持 OpenAI、Anthropic、Google、xAI、Ollama 和 vLLM 进行本地模型部署。


## 🎯 上手难度

进阶难度。前提条件包括 Python、GPU 和 API 密钥。步骤涉及克隆存储库并遵循设置说明。
