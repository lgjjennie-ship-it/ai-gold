## 📌 项目详解

GenOffice 是一个开源的 AI 办公套件，集成了 AI 代理，可以在本地编辑 .docx、.xlsx 和 .pptx 文件，使用 TypeScript 语言，并提供 CLI 用于脚本编写和自动化。 它凭借超过 10k 星和 1.4k 分叉、近期活跃度以及解决本地 AI 办公工具痛点，具有明显的 SaaS 或 API 集成盈利潜力，因此备受关注。 GenOffice 采用开源许可证，已投入生产，部署复杂度适中，需要本地硬件并集成 Claude Code 和 Codex 等 AI 代理。
