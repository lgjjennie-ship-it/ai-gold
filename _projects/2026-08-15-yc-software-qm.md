## 📌 项目详解

QM 是一个用 TypeScript 构建的多人代理 harness，旨在为协作工作环境设计。它为每个用户和房间提供隔离的内存、文件存储和权限，可在 Slack 和网络上运行。 QM 拥有 13,565 个星标和 1,597 个分支，显示出强烈的社区兴趣。它解决了多人代理 harness 的需求，暗示了通过 SaaS 或 API 进行货币化的潜力。 QM 遵循 MIT 许可证，处于生产成熟度，部署复杂度适中。它需要 TypeScript 并有 230 个开放问题。


## 🌐 背景与生态

一个多人代理 harness 是驱动 LLM 的循环，执行工具调用并反馈结果。QM 通过隔离的用户空间和工具持久性增强了协作工作环境。

QM 可用于远程工作和团队协作场景。它在人力资源和项目管理等行业中具有 SaaS 货币化的潜力。
