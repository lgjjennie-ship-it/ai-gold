## 📌 项目详解

T3MP3ST 是一个使用多智能体系统进行攻击性安全测试的自主红队平台，采用 TypeScript 进行开发。 T3MP3ST 以 6680 星和 1388 个分支、近期活动以及通过新颖的多智能体方法解决攻击性安全的关键领域而脱颖而出，提供清晰的 SaaS 或 API 货币化潜力。 T3MP3ST 遵循开源许可证，处于生产成熟度，部署复杂度适中，运行需要标准硬件。

多智能体系统在攻击性安全领域正获得关注，CyberStrikeAI 和 ARTEX 等框架展示了其效用。T3MP3ST 利用这一趋势，创建了一个自主的红队平台。
